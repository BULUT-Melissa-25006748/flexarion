Studio de développement de jeux vidéo indépendant basé à Aix-en-Provence, spécialisé dans les univers de science-fiction.

## 📌 À propos du projet
Ce dépôt héberge le code source du site web officiel du studio Flexarion, développé dans le cadre du concours de référencement du BUT Informatique.
L'objectif est d'optimiser le SEO technique, on-page et off-page pour atteindre la meilleure position sur Google sur le mot-clé inventé **Flexarion**.

## 🚀 Hébergement & Déploiement
Le site est codé en HTML/CSS pur et déployé en continu via GitHub Pages, une plateforme autorisée par le règlement, afin de garantir une publication en ligne et une indexation rapide.
